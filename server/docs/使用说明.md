# Local Dream ET Server  v1.0.0

版权所有 (C) 2026 etc  ——  本产品仅供本地学习与离线使用。

把一台普通电脑变成一个**本地、隐私、无需联网推理**的 AI 出图 HTTP API 服务。
真实出图引擎复用开源项目 **stable-diffusion.cpp**（MIT，
https://github.com/leejet/stable-diffusion.cpp ）的 CPU 推理 `sd-server`。
本程序只做：控制台向导、一键复制的主界面、API Key 鉴权、反向代理与看门狗。

---

## 1. 目录结构

```
LocalDreamET-Server/
├─ bin/
│  ├─ etserver      ← 本外壳（向导/主界面/鉴权代理/看门狗）
│  └─ sd-server     ← 真实出图引擎（stable-diffusion.cpp，CPU 推理）
├─ config/
│  ├─ etserver.conf        ← 首次运行自动生成（含你的 46 位 API Key）
│  ├─ etserver.conf.template
│  └─ banned.txt          ← 可选：内容限制开启后的本地违禁词表（每行一词）
├─ models/                ← 向导下载的模型放在这里
├─ scripts/start.sh       ← 启动脚本
└─ logs/                  ← 运行日志
```

## 2. 首次运行

直接运行 `bin/etserver`（或 `scripts/start.sh`）。第一次会进入控制台向导：

1. 列出与手机端 LocalDream 对齐的 CPU 模型（SD1.5 系列），输入编号；
2. 用 `curl` 从 HF 镜像（hf-mirror.com）断点续传到 `models/`，下载完做大小校验；
3. 完成后自动进入主界面并拉起引擎。

非首次启动直接进入主界面。

## 3. 主界面会展示三块（均可一眼看到）

- **服务地址**：`http://<局域网IP>:8080` ，以及 `http://127.0.0.1:8080`
- **API Key**：首次启动随机生成，**恰好 46 位**字母数字 `[A-Za-z0-9]`，
  存入 `config/etserver.conf`，重启不变；菜单里 `k` 可重置。
- **模型名称 / model id**。

主界面下方是实时日志。控制台命令：
`r` 重启引擎 · `f` 切换内容限制 · `k` 重置 Key · `i` 重新显示 · `q` 退出。

## 4. 兼容的调用方式（以上游真实端点为准）

对外默认监听 `0.0.0.0:8080`。除健康检查外，**所有端点都要带**：

```
Authorization: Bearer <你的46位Key>
```

（也支持 `X-API-Key: <Key>` 或 `?api_key=<Key>`）。

真实端点（本版本由上游 sd-server 提供，本外壳仅做鉴权转发）：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET  | `/healthz` | **公开**健康检查（免 Key），就绪返回 200 |
| POST | `/sdapi/v1/txt2img`   | sdapi/A1111 风格 文生图 |
| POST | `/sdapi/v1/img2img`   | sdapi 风格 图生图 |
| GET  | `/sdapi/v1/samplers` `/sdapi/v1/schedulers` `/sdapi/v1/sd-models` `/sdapi/v1/loras` `/sdapi/v1/upscalers` | 元信息 |
| POST | `/v1/images/generations` | OpenAI 风格文生图（上游真实提供） |
| POST | `/v1/images/edits`       | OpenAI 风格图编辑 |
| GET  | `/v1/models`             | OpenAI 风格模型列表 |
| POST | `/sdcpp/v1/img_gen`      | sd.cpp 原生异步文生图 |
| GET  | `/sdcpp/v1/capabilities` `/sdcpp/v1/jobs/{id}` | 能力 / 异步任务查询 |

> 说明：本服务为 **sd.cpp / sdapi 风格**。`/v1/...` 仅在上游确实实现时可用，
> 未实现的字段不会假装支持。

### 调用示例

```bash
# 健康检查（不需要 Key）
curl http://127.0.0.1:8080/healthz

# 受保护端点：不带 Key -> 401
curl -i http://127.0.0.1:8080/sdapi/v1/samplers

# 带 Key 调文生图（sdapi 风格）
curl -X POST http://127.0.0.1:8080/sdapi/v1/txt2img \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"prompt":"a cat", "width":512, "height":512, "steps":20, "batch_size":1}'
```

## 5. 看门狗（Watchdog）

外壳把 `sd-server` 作为子进程拉起并绑定 `127.0.0.1:17860`。看门狗每 2 秒探测一次：
子进程退出或健康检查失败即按 **1→2→4→…封顶30秒** 指数退避自动重启，
累计重启次数写入日志与 `/healthz`，可在日志里看到。

## 6. 内容限制

服务端**默认无限制**。在菜单按 `f` 开启后，会对 `/sdapi/v1/txt2img`、
`/sdapi/v1/img2img`、`/v1/images/generations`、`/sdcpp/v1/img_gen` 的提示词
做本地违禁词子串扫描（词表见 `config/banned.txt`，每行一个），命中即返回 400。
切换开/关会**自动重启引擎**使配置生效。

## 7. 平台说明

- **Linux x86_64**：原生 ELF，直接运行。headless 服务器可用
  `nohup ./scripts/start.sh > logs/server.log 2>&1 &` 后台运行。
- **Windows x86_64**：PE32+ 控制台程序，UTF-8 输出（雅黑等宽）。
  桌面环境下可最小化到系统托盘；无显示环境时用控制台/后台模式即可。
