访问与点击计数

第三方公开计数器 Abacus · 仅反映量级

访问 PV 与下载点击 PV 是首页真实埋点（自 v3.0.0-et.41 起才开始计数，更早访问无数据）。公开计数器不去重、不防刷，同一人刷新多次累加，也可能被浏览器广告拦截插件屏蔽，因此只能看量级趋势，不能当独立访客数。

  • 独立访客 UV：需要服务端用 Cookie/指纹去重，纯静态 GitHub Pages 做不到 → 显示 N/A，不估算、不伪造。
  • 访问来源 IP / 地域 / Referer / 访问日志：只有 HTTP 服务器（或 Worker/函数后端）能拿到并记录，静态托管拿不到 → 不显示假 IP、假地图。
  • 网站压力（QPS/带宽/在线数）：需服务器指标或 CDN 后台，Pages 无此数据 → 不展示。

数据口径：① 各版本/各文件下载次数、各端合计、最新版本，均实时读取 GitHub 官方 Releases API 的 download_count，由 GitHub 统计、无法伪造；浏览器匿名访问（每 IP 约 60 次/小时），限流时自动重试并使用 2 分钟会话缓存。GitHub 只提供“累计值”，不提供历史下载曲线，面板不画虚构趋势；“较上次 +N”来自本浏览器本地存储的上次读数。 ② 访问 PV / 点击 PV 为第三方计数器在首页的真实埋点，仅量级、不去重。 ③ 访问者真实 IP、地域、访问日志、UV 去重、服务端 QPS/带宽/压力，GitHub Pages 这类纯静态托管天然无法获取；若确实需要，应在自有后端（可在已常驻的 etserver 增加匿名上报/count 接口，或部署 Cloudflare Worker / EdgeOne 函数）采集——但沙箱环境非 7×24 在线，数据可能中断，故在没有稳定后端前不启用、不虚构任何 IP 与压力数字。 本页不在官网前台设置入口。刷新于 。
