Local Dream ET 官方使用文档

安卓端本地 AI 绘画（Stable Diffusion / Qwen Image），离线出图、无云端上传。开发者：ET · 当前手机版 v3.0.0-et.21（build 95，包名 etc.github.ai）：Illustrious/千问进入 CPU 列表并按 32/64 位机型解锁、修复自定义比例不生效、SD1.5 GPU(OpenCL) 默认开、健壮识别华为麒麟等非高通平台、更新包存 LocalDreamET/temp_downloads。et.20 修复 32/64 位本机转换 std::length_error 闪退与锁屏后台出图中断；et.19 起千问 Qwen Image 2.1 共 4 个量化版本 Q3_K/Q4_0/UC Q4_0/UC Q5_K_M；NPU 按机型加锁、Illustrious v16、系统安装器、MIT。

快速开始三步：
  1. 安装并打开，授予存储权限（模型与图片存到 /storage/emulated/0/LocalDreamET）；首次下载/安装更新时按提示允许安装未知应用。
  2. 在「CPU Models」选一个模型（新手推荐 ChilloutMix / Photon / DreamShaper），点下载，等待下载并在本机转换完成。
  3. 点进模型，输入提示词，点生成图像，结果在「生成结果」页，可保存到相册。

一、安装与权限

  • 支持 Android 9（API 28）及以上，安装包同时内置 arm64-v8a 与 armeabi-v7a，32 位手机可直接用 CPU/GPU 出图。
  • 需要的权限：网络（下载模型）、存储/所有文件访问（存模型和成品图）、通知（显示下载进度）、安装未知应用（应用内更新）。
  • 所有模型与文件都在公共目录 /storage/emulated/0/LocalDreamET（models/ 放模型，temp_downloads/ 放下载临时文件）；无该权限时回退到应用私有目录。

二、下载模型与下载源

模型分两类：预置包（下完即用）与转换类 SD1.5（先下约 2GB 原始权重，再在本机转换一次，之后直接用）。

切换下载源（下载慢时用）

模型列表右上角菜单 → 设置 → 下载地址，可选：

下载源说明
魔搭 ModelScope（默认·国内最快）阿里国内 CDN，国内下载快，推荐
hf-mirrorHugging Face 国内镜像，预置包默认走它
Hugging Face 官方海外官方源，国内可能较慢
自定义可填自己的镜像根地址

所选源作为首选，其它源会自动作为回退：某个源慢或连不上会自动换源续传，不会卡死。

断点续传 / 后台 / 关机恢复

  • 下载与转换在前台服务 + 通知栏进行，切后台、锁屏仍继续，通知栏显示进度。
  • 支持 HTTP Range 断点续传：断网、杀进程、关机重启后再次点击会接着下，不重头。
  • 只有转换成功写出完成标记才算“已下载”，半成品不会被当成可用模型，避免“一用就报错”。

从链接导入任意模型（先检测兼容性，再下载）

「CPU Models」页点 ＋ 从链接导入模型，可添加市面上常见的单文件 SD1.5（.safetensors）。可粘贴：Hugging Face 模型页 huggingface.co/作者/仓库、hf-mirror 页/直链、魔搭 ModelScope 页或 FilePath 直链、任意网站的 .safetensors 直链。

粘贴后点检测兼容性，App 联网做四项预检并给出结论：① 必须是根目录单 .safetensors（不支持 diffusers 文件夹 / .gguf / .ckpt）；② 用与下载器相同的源顺序实测真实大小，必须 ≤ 2.14GB，否则 32 位转换会崩；③ 剩余空间需约为文件 2 倍（下载+转换）；④ 读 safetensors 文件头确认是 SD1.5（含 U-Net time_embed 与 CLIP），SDXL / DiT（千问、Flux）结构直接判不支持，不会让你白下几个 GB。

显示「本手机支持」后点确认并下载：走内置前台服务下载（魔搭首选、断点续传、通知栏、后台/关机续传），下完自动转换；转换成功后该模型永久出现在列表，以后直接点用，和内置模型完全一致。个别站点不支持 Range/HEAD 取不到大小时，请改贴 hf-mirror 或魔搭链接再检测。

三、生成图片

  • 提示词：可输入任意长度，应用不做内容审查。SD1.5 底层只认英文标签，输入中文会整句在线翻译成英文（无网时用内置词典兜底）；Qwen Image 原生支持中文。
  • 负面提示词：填写不希望出现的内容，默认已带常见画质/瑕疵负向词。
  • 比例/尺寸：在生成页高级设置里选宽高比例（1:1、9:16、16:9 等）。SD1.5 宽高按 64 对齐，范围 128–512，避免非对齐导致马赛克。
  • 步数 / CFG：步数越高越细但越慢（低配建议 15–20）；CFG 建议 5–9，应用上限 9 以防止 32 位 fp16 溢出花屏。
  • 种子：留空每次随机；填同一数字可复现。

四、图生图（按原图改图）

  • 在生成页打开「图生图」，直接上传整张图片，不做强制裁剪或分割。
  • 重绘强度默认 0.45：数值越低越忠于原图（构图/姿态更像），越高改动越大。想要更像原图就调低，想大改就调高。

五、清晰度 / 放大（关于“4K”）

原生 4K（约 3840×2160，830 万像素）在 32 位低配手机上物理不可行：扩散按像素平方增长算力与内存，4K 相对 512² 约 32 倍负载，32 位进程会内存不足崩溃或耗时数十分钟。这不是软件限制。
实际做法：32 位默认 384、64 位默认 512（64 对齐、PNG 无损保存）保证清晰不花屏；需要更大尺寸时，用应用内的 高清放大（Upscaler）把成品放大到更高分辨率。

六、语言与主题

  • 模型列表菜单 → 设置 →「语言」：简体中文 / English / 繁體中文，点选后整个应用（含模型列表名称、描述、通知）立即刷新；如个别文字仍是旧语言，返回列表或重进页面即可。
  • 「外观」可切换深色/浅色与主题色，支持安卓 12+ 动态取色。

七、Qwen Image 2.1 与机型要求（et.16 起按机型过滤）

「NPU Models」标签页内置 Qwen Image 2.1、Qwen Image 2.1 UC Q4_0、Z-Image Turbo、FLUX.2 Klein 等大模型（约 6.7–10.8GB，走高通 Adreno NPU）。

  • 32 位手机：列表只显示能真实运行的 SD1.5 CPU/GPU 模型（几十个，含链接导入），不会出现点了才跑不动的大模型。
  • 64 位手机：列表显示全部模型；但大 DiT/SDXL 仍需对应芯片。下载前会再做一次硬件与内存预检——芯片不支持会提示“本手机无法运行”，内存不足会提示需要/现有内存并阻止下载，避免白下 10GB。
大 DiT 需要 骁龙 8 至尊版（SM8750）及以上、arm64、Android 12+；SDXL-NPU 需骁龙 8 Gen3（SM8650）及以上。32 位或其它芯片请使用「CPU Models」里的 SD1.5。

八、应用内更新（et.16 起多镜像加速）

  • 设置 → 检测更新，联网比对版本号；有新版会在应用内直接下载，完成后调起系统打包安装程序安装（首次需允许“安装未知应用”）。
  • 下载时会并行探测 GitHub 直链与多个国内加速镜像，自动选最快的一个，并支持断点续传（中断/杀进程后继续，不重头）。
  • 也可在官网或 GitHub Releases 手动下载最新 APK。

九、错误代码对照与解决方法

报错 / 代码含义解决方法
Failed to connect to localhost/127.0.0.1:8081本地推理引擎没启动好或模型未转换成功。退出模型页重进、等“已下载”状态；确认没被安全软件禁止执行本地程序；仍不行则删除该模型重新下载转换。
ETIMEDOUT / failed to connect to huggingface.co ...:443海外源连不上/超时。设置里把下载源切到魔搭 ModelScope 或 hf-mirror；网络恢复会自动换源续传。
Executable not found .../lib/arm/libstable_diffusion_core.so老版本 32 位缺原生引擎（et.12 起已修复）。更新到最新版；卸载旧版后全新安装。
Cannot read tensor data: model.diffusion_model.time_embed.0.weight / 退出码 134原始权重超过 32 位 2.14GB 寻址上限或文件不是 SD1.5，转换崩溃。用列表内置模型或“链接导入”预检通过的单文件 SD1.5（≤2.14GB）；SDXL/DiT 文件会被预检拒绝。
Prompt empty点生成时正向提示词为空。在“图像生成提示”框里输入内容（中文会自动翻译成英文标签）。
生成结果全是马赛克/碎玻璃尺寸未 64 对齐、CFG 过高导致 fp16 溢出，或模型没转完整。用应用内置比例、CFG≤9；确认显示“已下载”；必要时删除重下。
成品模糊/变形/不听提示词分辨率过低、步数太少，或中文整句翻译没生效。步数调到 20–28；使用具体英文标签或保持联网让中文整句翻译生效；需要大图用“高清放大”。
本手机无法运行 / 内存不足（下载弹窗）大模型需要更新的 64 位 NPU 或更大内存。在本设备改用 SD1.5 模型；或换符合要求的手机下载该大模型。
通知栏无下载进度 / 切后台就停未授通知权限或被系统限制后台。授予通知权限；在系统电池设置里把本应用设为“不限制后台/允许后台活动”。
安装时点了没反应未允许“安装未知应用”。按弹窗跳到系统设置允许本应用安装，再点一次更新。
HTTP 4xx/5xx（更新下载）镜像临时异常。稍后重试；应用会自动切换其它镜像，也可去官网/Release 手动下载。

遇到表里没有的错误，请把完整英文原文（含退出码）发给开发者 ET 以便定位。

十、常见问题

下载慢 / 超时

把下载源切到「魔搭 ModelScope」；应用更新走多镜像自动选最快；确认网络正常；中断后直接续传即可。

后台/锁屏不能生成、发热大

et.16 起生成服务持有唤醒锁并使用大堆；请在系统设置允许后台活动。低配机建议步数 15–20、尺寸 384，发热与耗时会明显下降。

转换失败 / 退出码 134

多为原始权重超过 32 位 2.14GB 寻址上限的旧模型；列表内现有模型均经过文件头校验、32 位可安全转换。若仍报错，把英文报错发开发者。

成品发糊/不听提示词

用英文质量标签或让中文整句翻译生效；提高步数到 20–25；需要高分辨率用放大功能。
