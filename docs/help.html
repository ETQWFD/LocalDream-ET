Local Dream ET 官方使用文档

安卓端本地 AI 绘画（Stable Diffusion / Qwen Image），离线出图、无云端上传。开发者：ET · 当前手机版 v3.0.0-et.25（build 99，包名 etc.github.ai）：修复 SD1.5 点生成即“未知错误/无法连接 8081”——错误按真实原因分类（崩溃信号/内存不足/ABI 或 .so 加载失败/模型缺件损坏/超时），“图生图”未选图时自动按文生图不再空图崩引擎，启动前自检模型产物，预构建包下载做 zip CRC 与产物完整性闸门、断点续传坏包重下；英文/负向提示完全离线逐字透传、中文无网本地继续；检测更新改前台服务不中断；模型列表两个加号合并；新增「关于→导出诊断日志」。et.23 修复转换假完成/卡死（退出码0＋6产物齐全＋原子标记＋收尾提示）。电脑版为 v3.0.1（与手机同款界面、52 个模型、真实校验就绪状态机、统一 models/outputs/tmp/config 目录、设置可滚动、窗口可缩放最大化）。et.21 起 Illustrious/千问进入 CPU 列表并按 32/64 位机型解锁、SD1.5 GPU(OpenCL) 默认开；et.20 修复 32/64 位本机转换闪退与锁屏后台中断；et.19 起千问 Qwen Image 2.1 共 4 个量化版本；NPU 按机型加锁、Illustrious v16、系统安装器、MIT。

快速开始三步：
  1. 安装并打开，授予存储权限（模型与图片存到 /storage/emulated/0/LocalDreamET）；首次下载/安装更新时按提示允许安装未知应用。
  2. 在「CPU Models」选一个模型（新手推荐 ChilloutMix / Photon / DreamShaper），点下载，等待下载并在本机转换完成。
  3. 点进模型，输入提示词，点生成图像，结果在「生成结果」页，可保存到相册。

一、安装与权限

  • 支持 Android 9（API 28）及以上，安装包同时内置 arm64-v8a 与 armeabi-v7a，32 位手机可直接用 CPU/GPU 出图。
  • 需要的权限：网络（下载模型）、存储/所有文件访问（存模型和成品图）、通知（显示下载进度）、安装未知应用（应用内更新）。
  • 所有模型与文件都在公共目录 /storage/emulated/0/LocalDreamET（models/ 放模型，temp_downloads/ 放下载临时文件）；无该权限时回退到应用私有目录。

二、下载模型与下载源

模型分两类：预置包（下完即用）与转换类 SD1.5（先下约 2GB 原始权重，再在本机转换一次，之后直接用）。

切换下载源（下载慢时用）

模型列表右上角菜单 → 设置 → 下载地址，可选：

下载源说明
魔搭 ModelScope（默认·国内最快）阿里国内 CDN，国内下载快，推荐
hf-mirrorHugging Face 国内镜像，预置包默认走它
Hugging Face 官方海外官方源，国内可能较慢
自定义可填自己的镜像根地址

所选源作为首选，其它源会自动作为回退：某个源慢或连不上会自动换源续传，不会卡死。

断点续传 / 后台 / 关机恢复

  • 下载与转换在前台服务 + 通知栏进行，切后台、锁屏仍继续，通知栏显示进度。
  • 支持 HTTP Range 断点续传：断网、杀进程、关机重启后再次点击会接着下，不重头。
  • et.23 起，转换成功的唯一标准是：转换进程退出码为 0、写出完成标记，且 6 个输出文件（clip/unet/vae_decoder/vae_encoder 权重与 pos_emb/token_emb）都存在、非空、字节数与清单一致。进度到 100% 后会进入“正在收尾写入”阶段（最后一个大张量落盘较慢，属正常，请勿关闭）；半成品不会被当成可用模型，失败会保存日志并允许重试，重启后也不会把残缺产物误判为已转换。

从链接导入任意模型（先检测兼容性，再下载）

「CPU Models」页点 ＋ 从链接导入模型，可添加市面上常见的单文件 SD1.5（.safetensors）。可粘贴：Hugging Face 模型页 huggingface.co/作者/仓库、hf-mirror 页/直链、魔搭 ModelScope 页或 FilePath 直链、任意网站的 .safetensors 直链。

粘贴后点检测兼容性，App 联网做四项预检并给出结论：① 必须是根目录单 .safetensors（不支持 diffusers 文件夹 / .gguf / .ckpt）；② 用与下载器相同的源顺序实测真实大小，必须 ≤ 2.14GB，否则 32 位转换会崩；③ 剩余空间需约为文件 2 倍（下载+转换）；④ 读 safetensors 文件头确认是 SD1.5（含 U-Net time_embed 与 CLIP），SDXL / DiT（千问、Flux）结构直接判不支持，不会让你白下几个 GB。

显示「本手机支持」后点确认并下载：走内置前台服务下载（魔搭首选、断点续传、通知栏、后台/关机续传），下完自动转换；转换成功后该模型永久出现在列表，以后直接点用，和内置模型完全一致。个别站点不支持 Range/HEAD 取不到大小时，请改贴 hf-mirror 或魔搭链接再检测。

三、生成图片

  • 提示词：可输入任意长度，应用不做内容审查。SD1.5 底层只认英文标签，输入中文会整句在线翻译成英文（et.22 起联网翻译超时缩短到 4 秒，失败更快安全回退；任何翻译只用于英文模型、不会替换你写的英文/负向提示词原文，无网时用内置词典兜底）；Qwen Image 原生支持中文，中文提示词逐字生效。
  • 负面提示词：填写不希望出现的内容，默认已带常见画质/瑕疵负向词。
  • 比例/尺寸：在生成页高级设置里选宽高比例（1:1、9:16、16:9 等）。SD1.5 宽高按 64 对齐，范围 128–512，避免非对齐导致马赛克。
  • 步数 / CFG：步数越高越细但越慢（低配建议 15–20）；CFG 建议 5–9，应用上限 9 以防止 32 位 fp16 溢出花屏。
  • 种子：留空每次随机；填同一数字可复现。

四、图生图（按原图改图）

  • 在生成页打开「图生图」，直接上传整张图片，不做强制裁剪或分割。
  • 重绘强度默认 0.45：数值越低越忠于原图（构图/姿态更像），越高改动越大。想要更像原图就调低，想大改就调高。

五、清晰度 / 放大（关于“4K”）

原生 4K（约 3840×2160，830 万像素）在 32 位低配手机上物理不可行：扩散按像素平方增长算力与内存，4K 相对 512² 约 32 倍负载，32 位进程会内存不足崩溃或耗时数十分钟。这不是软件限制。
实际做法：32 位默认 384、64 位默认 512（64 对齐、PNG 无损保存）保证清晰不花屏；需要更大尺寸时，用应用内的 高清放大（Upscaler）把成品放大到更高分辨率。

六、语言与主题

  • 模型列表菜单 → 设置 →「语言」：简体中文 / English / 繁體中文，点选后整个应用（含模型列表名称、描述、通知）立即刷新；如个别文字仍是旧语言，返回列表或重进页面即可。
  • 「外观」可切换深色/浅色与主题色，支持安卓 12+ 动态取色。

七、Qwen Image 2.1 与机型要求（et.16 起按机型过滤）

「NPU Models」标签页内置 Qwen Image 2.1、Qwen Image 2.1 UC Q4_0、Z-Image Turbo、FLUX.2 Klein 等大模型（约 6.7–10.8GB，走高通 Adreno NPU）。

  • 32 位手机：列表只显示能真实运行的 SD1.5 CPU/GPU 模型（几十个，含链接导入），不会出现点了才跑不动的大模型。
  • 64 位手机：列表显示全部模型；但大 DiT/SDXL 仍需对应芯片。下载前会再做一次硬件与内存预检——芯片不支持会提示“本手机无法运行”，内存不足会提示需要/现有内存并阻止下载，避免白下 10GB。
大 DiT 需要 骁龙 8 至尊版（SM8750）及以上、arm64、Android 12+；SDXL-NPU 需骁龙 8 Gen3（SM8650）及以上。32 位或其它芯片请使用「CPU Models」里的 SD1.5。

八、应用内更新（et.16 起多镜像加速）

  • 设置 → 检测更新，联网比对版本号；有新版会在应用内直接下载，完成后调起系统打包安装程序安装（首次需允许“安装未知应用”）。
  • 下载时会并行探测 GitHub 直链与多个国内加速镜像，自动选最快的一个，并支持断点续传（中断/杀进程后继续，不重头）。
  • 也可在官网或 GitHub Releases 手动下载最新 APK。

Prompt empty点生成时正向提示词为空。在“图像生成提示”框里输入内容（中文会自动翻译成英文标签）。

成品模糊/变形/不听提示词分辨率过低、步数太少，或中文整句翻译没生效；旧版本保存相册用 JPEG 有损。升级到 et.22：成品保存相册已改无损 PNG、中文翻译失败安全回退不替换原文；步数保持 20 左右；可保持联网让中文整句翻译生效；需要大图用“高清放大”。
本手机无法运行 / 内存不足（下载弹窗）大模型需要更新的 64 位 NPU 或更大内存。在本设备改用 SD1.5 模型；或换符合要求的手机下载该大模型。
通知栏无下载进度 / 切后台就停未授通知权限或被系统限制后台。授予通知权限；在系统电池设置里把本应用设为“不限制后台/允许后台活动”。
安装时点了没反应未允许“安装未知应用”。按弹窗跳到系统设置允许本应用安装，再点一次更新。
HTTP 4xx/5xx（更新下载）镜像临时异常。稍后重试；应用会自动切换其它镜像，也可去官网/Release 手动下载。

遇到表里没有的错误，请把完整英文原文（含退出码）发给开发者 ET 以便定位。

十、常见问题

下载慢 / 超时

把下载源切到「魔搭 ModelScope」；应用更新走多镜像自动选最快；确认网络正常；中断后直接续传即可。

后台/锁屏不能生成、发热大

et.16 起生成服务持有唤醒锁并使用大堆；请在系统设置允许后台活动。低配机建议步数 15–20、尺寸 384，发热与耗时会明显下降。

转换失败 / 退出码 134

多为原始权重超过 32 位 2.14GB 寻址上限的旧模型；列表内现有模型均经过文件头校验、32 位可安全转换。若仍报错，把英文报错发开发者。

转换卡在最后 / 提示完成却没转好（假完成）

请升级到 v3.0.0-et.23：转换有真实张量级进度，进度到 100% 后显示“正在收尾写入”，最后一个大张量与 VAE 落盘本就较慢（长时间无新进度会提示“仍在转换”，不会误杀）；只有退出码为 0 且 6 个输出文件齐全、大小与清单一致才算成功。若失败，应用临时目录下会生成 convert_*.log，把该日志连同机型/SoC/安卓版本发开发者；已下载的源会保留，点重试不会重新下载。

点生成提示“未知错误 / 无法连接 8081”

请升级到 v3.0.0-et.24：现在会显示真实原因（引擎崩溃信号 / 内存不足被系统杀死 / .so 加载失败或 ABI 不符 / 模型文件缺失或损坏 / 连接超时），而不是统一文案。常见诱因是模型没下完整或损坏——应用在启动引擎前会自检 6 个产物，缺件会提示重新下载；预构建模型包下载也已加 zip 完整性校验、断点续传与坏包重下。若“图生图”标签高亮但没选图，et.24 会自动按文生图处理，不再空图导致引擎崩溃。仍失败时请用下方“导出诊断日志”回传。

导出诊断日志（反馈首选）

在模型列表右上角/设置里打开“关于”，点“导出诊断日志”，会在公共目录 /storage/emulated/0/LocalDreamET/ 生成 diagnostics_时间.txt 并弹出分享。内容含：App 版本、机型/SoC/ABI/安卓版本/内存、各模型目录文件与字节、引擎日志 engine_*.log、转换日志 convert_*.log、最近 logcat、各下载源 HTTP 状态。把该文件发开发者即可一次性定位，无需截图描述。

断网 / 飞行模式能否出图

可以。本地 SD1.5 出图不依赖网络：英文与负向提示词一律不联网、逐字生效；仅中文提示词会在有网时做在线整句翻译增强，无网或超时会立即改用内置词典/原文继续，不会因此报错或卡住。

成品发糊/不听提示词/生成卡顿

请使用最新版：相册成品为无损 PNG、英文/负向提示词逐字透传、中文翻译失败安全回退、过程预览降采样并节流；1:1 实际输出 512×512、各边 64 对齐，步数 20 / CFG 7 / dpm 默认，需要大图用放大功能，低配机尺寸用 384 更流畅。转换/出图耗时随分辨率（像素平方）上升、老旧 32 位 CPU 更久，属正常物理开销，非卡顿 bug。

出图满屏碎玻璃 / 马赛克噪声（et.25 重点修复）

多发生在部分 Adreno/Mali 机型用 GPU(OpenCL) 出图或图生图时，属于底层 fp16 计算发散。et.25 起应用会对每张结果做健康检测：一旦判定为纯色/裁切/纯随机噪声，坏图不会保存；若本次开着 GPU，会自动关闭 GPU、改用 CPU 安全参数（CFG 7 / dpm++2m / 20 步 / 512）重画一次，成功后记住“本机 GPU 不稳定”、以后默认 CPU（你仍可在设置手动再开）。若 CPU 重画仍是碎玻璃，更可能是模型文件损坏，应用会提示并提供“重新校验/重转/重新下载”。图生图重绘强度默认 0.45、限制在 0.3–0.7，避免强度过高退化成噪声。若升级后仍出现，请在右上角“日志”页把 HEALTH_BAD 与 engine_*.log 发回。

图片比例切换不生效（et.25 修复）

GPU/QNN 版同名 SD1.5（如 Anything V5.0）此前点 1:1/3:4/4:3 只改文字。et.25 起所有 SD1.5（CPU 与 GPU）都会按比例真实重算像素（64 对齐）并让引擎按新尺寸重启，参数行会显示真实像素（如 512×512 / 384×512）。

“日志”页怎么用（et.25 新增）

模型列表右上角三点菜单 → 日志。集中显示引擎启动/崩溃、模型下载、转换、生成、更新、云上传等事件，并落盘到 /storage/emulated/0/LocalDreamET/logs/app.log（单文件约 2MB、保留 3 个自动滚动覆盖，应用不提供手动删除）。可按类别过滤、整段或单条复制、分享；登录云备份后还可一键上传到云端 log/。

云备份：如何生成并填写令牌（PAT）

应用不要求也不接收你的账号密码，使用各平台官方的“个人访问令牌(PAT)”：
· GitHub：网页登录后 头像 → Settings → Developer settings → Personal access tokens → 选 Tokens (classic) 或 Fine-grained token → Generate，勾选/授予 repo（仓库读写）权限，复制生成的令牌。
· Gitee：头像 → 设置 → 安全设置 → 私人令牌 → 生成新令牌，勾选 projects 等所需权限后复制。
然后在应用 设置 → 账号/云备份 选择平台、粘贴令牌；应用会先校验并显示你的账号名，再自动创建私有仓库 LocalDreamET-Backup（已存在则复用）。成品图“上传”进 png/、日志进 log/，重名不覆盖。令牌只用 Android 系统密钥库加密保存、不会出现在日志或诊断里，可随时“退出登录”清除。未登录或无网络时本地一切照常可用，仅上传按钮禁用并提示。

更新下载中断 / 装不上 / 模拟器（et.25）

更新安装包保存在 LocalDreamET/temp_downloads，下到一半关闭后再更新会用 HTTP Range 断点续传（仅当服务器支持且总大小一致才续，不会盲目清空已下部分），前台服务＋通知使切后台不中断；完成优先直调系统 PackageInstaller，失败回退文件安装器并可引导“允许安装未知应用”、打开安装包所在目录。更新源 GitHub 优先，连不上时自动尝试 Gitee 镜像。纯 x86/x86_64 模拟器没有 ARM 原生引擎（也无可用 x86_64 引擎），应用会明确提示“请使用真机或 arm64 镜像”，不会崩溃或假成功。

et.26 常见问题（云备份 / 模拟器 / 日志）

1. 云备份令牌怎么取？ GitHub：Settings → Developer settings → Personal access tokens → 生成 Classic 令牌并勾选 repo；若用 fine-grained 令牌需包含 Administration（建仓）与 Contents（读写）权限。登录时若提示 403 “Resource not accessible”，说明该令牌无建仓权限，改用 Classic 令牌或选“使用已有仓库”手动填 owner/repo 绑定。Gitee：头像 → 设置 → 私人令牌 → 生成新令牌，勾选 user_info、projects。上传后成品 PNG 在私有仓库 png/、日志在 log/。令牌只存本机系统密钥库，可退出登录。

2. 设备码授权是什么？ GitHub 设备码授权需开发者注册 OAuth Apps 拿到 client_id（设备流无需 secret）；在未配置 client_id 前该入口暂不可用，不影响用 PAT 登录。

3. 关注/Star 登录流程里默认勾选、可随时取消；失败只写日志，不影响登录与上传。

4. 模拟器/虚拟机支持：本版内置 x86_64 原生引擎，纯 x86_64 模拟器可原生跑 SD1.5；若设备无匹配 ABI 会给出中文提示，请换 arm64 真机或支持 ARM 转译的镜像。

5. 更新双源与断点续传：GitHub 优先、Gitee 兜底；下载采用 .part 断点续传（仅当服务器回 206 且大小一致才续），安装时若提示“未知来源”请按引导允许后返回自动续装。

6. 日志与错误位置：右上角三点“日志”查看运行日志；“关于 → 导出诊断日志”打包引擎/转换/下载/机型信息；公共目录 LocalDreamET/logs/app.log、engine_*.log、convert_*.log。应用可完全离线出图，联网仅用于云备份/更新。

et.27 常见问题（后台保活 / 修图 / 机型门槛 / 内存）

1. 熄屏后下载/转换/生成中断？ 这三类任务现在都以前台服务运行并持有 WakeLock 与 Wi-Fi 锁；首次发起长任务时会引导你关闭电池优化（可跳过，但跳过可能被系统挂起）。应用被回收后，下载按 .part 断点续传，转换按原子 finished 与 6 个产物对账，半成品不会显示为完成。

2. 修图模式怎么用？ 右上角三点选“修图”→ 选一个已下载且本机可用的模型 → 上传整张图（不裁剪）→ 填中文正向/负向提示 → 调重绘强度（0.3–0.7，默认 0.45）→ 点“修改图片”。结果进历史，可保存到相册或云备份。自动反推提示词暂未内置，直接用中文描述即可。

3. 哪些手机能跑大模型？ SD1.5 在全部 64 位安卓机（含华为麒麟、联发科、Exynos、Tensor）都能 CPU/GPU 跑，无 OpenCL 自动回退 CPU。SDXL/DiT/千问等大模型当前仅支持骁龙 Hexagon NPU（SM8650/8750 级别），华为等无 Hexagon 的机型 App 会如实锁定、不假标。

4. 图片尺寸/比例：长边按内存自适应（≤6GB 512、≤10GB 640、>10GB 768，均 64 对齐），支持 1:1/2:3/3:4/4:3/3:2/9:16/16:9 与自定义。

5. 提示“内存不足 std::bad_alloc”：降低图片尺寸或步数后重试，或关闭其他后台应用。低内存设备会自动使用更保守的默认尺寸。

6. 出图碎玻璃/马赛克：App 会自动检测并关闭 OpenCL、用 CPU 安全参数重试一次；若 CPU 仍异常会提示“疑似模型文件损坏”，可重新校验或重新下载模型。

et.28 常见问题（后台保活 / 厂商设置 / 日志 / 修图）

1. 熄屏后任务为什么会停？ 下载、解压、转换、生成、更新、修图现在都以前台服务运行并持有 WakeLock 与 Wi-Fi 锁；但国产 ROM 的电池/自启动管理可能仍会在熄屏或锁屏后清理后台。请在系统设置里允许本应用“自启动/后台运行/锁屏不清理/电池不优化”，首次发起长任务时 App 会引导。

2. 各品牌后台设置路径：华为/荣耀——手机管家→应用启动管理→允许手动管理；小米/Redmi——设置→应用设置→授权管理→自启动，电池→应用省电→无限制；OPPO/一加/realme——设置→电池→应用电池管理→允许后台运行；vivo/iQOO——设置→电池→后台高耗电→允许；三星——设置→设备维护→电池→后台使用限制→不加入休眠。不同系统版本菜单名可能略有差异。

3. 日志与诊断位置：App 内右上角“日志”、导出诊断；公共目录 LocalDreamET/logs/app.log，以及 engine_*.log、convert_*.log、crash_*.log。诊断信息包含服务是否在前台、锁是否持有、是否在电池白名单、设备厂商。

4. 修图模式：右上角三点“修图”→选一个已下载且本机可用的模型→上传整张图（不裁剪）→填中文正向/负向提示（负向词已预填可改）→调重绘强度（0.3–0.7，默认 0.45）→点“修改图片”，结果进历史可保存/云备份。

5. 微信/QQ 打不开或“已停止访问”：平台可能对未 ICP 备案域名直接拦截，网页无法解除。请点右上角 ··· 选择“在浏览器打开/在 Safari 或 Chrome 中打开”，或直接到 GitHub Release 页下载。
