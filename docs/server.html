快速上手

  • Windows：双击 EXE 安装，运行 etserver。Linux：tar xzf 解压后 ./etserver。
  • 启动后控制台打印四样：[服务地址] http://<IP>:<端口>、[API Key]（46 位）、[模型名]、[云备份状态]，填进手机 App「设置 → API 连接」。
  • 外壳先绑端口、后台加载模型：GET /healthz 返回 200 ready 可出图，503 表示模型加载中。
  • 默认 0.0.0.0:8080；被占用自动顺延下一个可用端口，以启动 banner 为准。
CONFIG FILES

ghost.txt / tip.txt

ghost.txt（自动云备份）

首次启动在程序目录生成模板，第一行填你自己的 ghp_ GitHub 令牌：

gh:ghp_你的GitHub令牌

出图后自动上传到私有仓 LocalDreamET-Upload（不存在自动创建）。不填则关闭云备份，图只落本地。

tip.txt（默认提示词模板）

512x512
正向提示词，例如：masterpiece, best quality, 1girl
反向提示词，例如：lowres, bad anatomy, watermark

第一行尺寸（宽x高）；其后正向 / 反向模板。API 显式传参时以请求为准。

API REFERENCE

API 速查

除 /healthz 外都要带 Key，三选一：Authorization: Bearer <key>、X-API-Key: <key>、?api_key=<key>。

端点用途
GET /healthz免 Key 探活：200 ready / 503 loading
POST /sdapi/v1/txt2imgA1111 文生图，返回 images[] base64
POST /sdapi/v1/img2img图生图，init_images 传 base64 data URI
POST /v1/images/generationsOpenAI 风格，返回 data[].b64_json

txt2img 示例：

curl -X POST http://127.0.0.1:8080/sdapi/v1/txt2img \
  -H "Authorization: Bearer <46位KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "a cute cat, best quality",
    "width": 512, "height": 512,
    "steps": 30, "batch_size": 6
  }'

frpc 内网穿透：在 VPS 跑 frps，本地 frpc 把 8080 映射到远程端口，手机 App 填 http://<VPS_IP>:<remote_port>。
