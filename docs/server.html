快速上手

  • Windows：双击 EXE 安装，运行 etserver（或开始菜单快捷方式）。
  • Linux：tar xzf LocalDreamET-Server-1.3.0-linux-x86_64.tar.gz && cd 解压目录 && ./etserver。
  • 启动后控制台会打印四样关键信息，把它们填进手机「ET 聊天画师 → 设置」即可连：
    • [服务地址] http://<局域网IP>:<实际端口>
    • [API Key]：固定 46 位字母数字串（首次启动随机生成，写入 config/etserver.conf 的 api_key=）
    • [模型名]：当前加载的模型 id（如 sd15-anythingv5）
    • [云备份状态]：是否已配置 ghost.txt
  • 外壳先绑定端口、再后台加载模型：启动后立刻可用 GET /healthz 探测；返回 200 ready 才出图，503 表示模型还在加载，手机端会显示「模型加载中」，不会卡死。

自动选端口

默认监听 0.0.0.0:8080。若 8080 被占用，外壳会自动顺延探测下一个可用端口，实际端口以启动 banner 为准（也可在 /healthz 返回里看到）。内部推理引擎固定在 127.0.0.1:17860+，不对外。

同一局域网即可访问；手机与电脑需在同一 WiFi / 物理网卡网段。防火墙请放行实际端口。

ghost.txt（出图自动云备份）

首次启动会在程序目录生成模板 ghost.txt，内容形如：

gh:ghp_你的GitHub令牌
  • 把上面这一行换成你自己的 ghp_ 开头 GitHub 令牌，保存后重启服务端。
  • 此后每次生成的图，会经 curl 自动上传到你的私有仓库 LocalDreamET-Upload；该仓库不存在时会自动创建（私有）。
  • 换号 / 换令牌就只改这一行；令牌只从该文件读取，不进程序日志、不进接口响应。
  • 不填或删掉这行 = 关闭云备份，图只落在本地。

tip.txt（默认出图参数模板）

首次启动在程序目录生成 tip.txt，用于给手机 / API 提供默认的尺寸与提示词模板：

512x512
正向提示词，例如：masterpiece, best quality, 1girl
反向提示词，例如：lowres, bad anatomy, watermark
  • 第一行是尺寸 宽x高（SD1.5 建议 512）。
  • 其后为正向 / 反向提示词模板；不改就一直用这份，改完即生效。
  • API 请求里若自带 width/height/prompt 等字段，以请求为准，本模板不覆盖。

默认参数（v1.3.0）

项默认说明
steps30采样步数，客户端请求自带则不覆盖
batch / n6一次出几张，引擎内部 batch 一次出齐、不重启
cfg_scale7.0引导系数
尺寸512x512受 tip.txt 模板影响
threads自动取本机逻辑核，保底 2、上限 8（config 可改）
content_filter0默认无关键词拦截 / 不注入负面词

引擎单实例常驻，模型启动时加载一次，出图请求经反代转发，不在每次请求时重载。

API 速查

除 /healthz 外，所有请求必须带 46 位 Key，三选一：Authorization: Bearer <key>、X-API-Key: <key>、或 ?api_key=<key>。

端点用途
GET /healthz免 Key 探活：200 ready 可出图 / 503 loading 加载中
POST /sdapi/v1/txt2imgA1111 文生图，返回 images[] base64
POST /sdapi/v1/img2img图生图，init_images 传 base64 data URI
POST /v1/images/generationsOpenAI 风格，返回 data[].b64_json
GET /sdapi/v1/sd-models 等模型 / 采样器等列表，原样透传

Linux 保活示例：

# nohup 后台运行
nohup ./etserver > etserver.log 2>&1 &

# systemd（/etc/systemd/system/etserver.service）
[Unit]
Description=Local Dream ET Server
After=network.target
[Service]
WorkingDirectory=/opt/etserver
ExecStart=/opt/etserver/etserver
Restart=on-failure
[Install]
WantedBy=multi-user.target
# 快速自测（替换端口与 key）
curl http://127.0.0.1:8080/healthz
curl -X POST http://127.0.0.1:8080/sdapi/v1/txt2img \
  -H "Authorization: Bearer <46位key>" -H "Content-Type: application/json" \
  -d '{"prompt":"a cat, best quality","steps":30,"batch_size":6}'
诚实说明：服务端要真出图，仍需自行运行包内附带的 download-cpu-model.sh 下载 CPU 大模型（SD1.5，约 1.6–4.3GB 视模型），并在 ghost.txt 填入真实 ghp_ 令牌才能云备份。本发布包与官网页面未在沙箱内端到端跑图；上述 API 字段与默认值来自代码契约（SERVER-API.md v1.3.0）。
