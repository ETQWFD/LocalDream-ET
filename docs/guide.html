USER GUIDE

使用手册

从安装到出图，手机版与电脑服务端的完整步骤。

ANDROID APP

手机版使用

1
下载并安装 APK官网首页点「下载安卓版」，允许安装未知来源 App。
2
下载模型进入模型页，选一个 SD1.5 模型下载；或把模型文件放到公共目录 LocalDreamET/models。
3
文生图输入英文提示词（可加反向提示词），选 512×512、steps 20–30，点生成。
4
图生图修图上传参考图，重绘强度 0.3–0.7，只改局部不整体重画。
5
云备份设置里填入 GitHub/Gitee 私有仓令牌，出图自动备份，令牌只存系统密钥库。
6
打分评论官网评分区点星星，每设备一票；可留昵称和反馈。
PC SERVER

电脑服务端使用

1
下载安装包服务端页下载 Windows EXE 或 Linux tar.gz。
2
启动 etserverWindows 双击安装后运行；Linux 解压后 ./etserver。控制台会打印地址、46 位 API Key、模型名。
3
连接手机手机与电脑同一 WiFi，在 App 设置里填 http://<电脑IP>:8080 和控制台打印的 Key。
4
API 调用A1111 兼容：POST /sdapi/v1/txt2img，Header 带 Authorization: Bearer <key>。
5
外网访问（frpc 穿透）VPS 跑 frps，本地 frpc 把 8080 映射到远程端口，手机填 http://<VPS_IP>:<端口>。

curl 示例

curl -X POST http://127.0.0.1:8080/sdapi/v1/txt2img \
  -H "Authorization: Bearer <46位KEY>" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"a cat, best quality","width":512,"height":512,"steps":30}'
FAQ

常见问题

出图很慢 / 内存不足？

降低分辨率到 256×256，步数降到 8–15；或改用电脑服务端出图。

NPU 不生效？

QNN NPU 仅骁龙 Hexagon 机型支持，其它自动用 CPU。

读不到模型列表？

给 App「所有文件访问」权限，模型放到 LocalDreamET/models。

服务端手机连不上？

确认同 WiFi、防火墙放行 8080、Key 复制完整；外网用 frpc。

微信里打不开？

点右上角「···」用系统浏览器打开。
