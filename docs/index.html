核心特性

把大模型装进手机，数据不出本机，离线也能出图。

NPU / CPU / GPU

SD1.5 支持 Hexagon V68 及以上骁龙 NPU；SDXL 支持骁龙 8 Gen 3 及以上；其它机型可用 CPU/GPU（OpenCL）推理。

检测更新如何工作

更新清单由本官网（GitHub Pages）提供，应用启动检测时读取 update.json，版本号更高则提示更新。

  1. 打开 App → 右上角菜单 → 设置。
  2. 点击最下方的 检测更新，应用联网比对 versionCode。
  3. 有新版本时点「下载并安装」，安装包在应用内下载并实时显示百分比与已下载大小。
  4. 首次使用会跳到系统设置，允许本应用「安装未知应用」，返回后自动继续。
  5. 下载完成立即调起安卓系统打包安装程序（Package Installer），确认即可覆盖安装，全程不经过文件管理器或应用商店。

安装说明

① 下载 APK

点击顶部「下载最新 APK」，或到 GitHub Releases 下载 LocalDream-ET.apk。

② 允许安装

安装时若系统提示，请允许当前浏览器/应用「安装未知应用」。

③ 下载模型

首次进入在模型列表选择 SD1.5 / SDXL 模型下载；CPU/GPU 模型适配更多机型。

④ 开始生成

输入提示词即可本地出图，无需联网上传图片。

架构与机型兼容

安装包包含两种 ABI，系统会自动匹配。

arm64-v8a · 64 位 NPU 加速（骁龙） CPU / GPU armeabi-v7a · 32 位 仅 CPU / GPU

✅ 32 位：v3.0.0-et.2 起安装包已内置 armeabi-v7a 原生 CPU/GPU（MNN/OpenCL）引擎，32 位手机可直接转换模型与出图，无需自行编译。NPU 所用的高通 QNN 库仅有 64 位版本，因此 32 位设备走 CPU/GPU 引擎； 大模型（尤其 SDXL）对内存要求较高，32 位设备建议使用 SD1.5。

电脑版 v3.0.0（Windows x64）

使用 C（Win32）＋ Python 编写的原生桌面程序，界面与手机版同款；底层为开源 stable-diffusion.cpp（leejet, MIT）CPU 引擎，Windows 10/11 64 位本地离线出图，免费、不上传图片。右键程序“属性→详细信息”显示开发者 ET / Copyright (C) 2026 ET。

① 下载安装

点顶部「下载电脑版安装包 v3.0.0」（按用户安装、无需管理员/UAC），或下免安装 ZIP 解压即用；安装版自动创建桌面与开始菜单快捷方式，可在设置里检测更新。

② 手机同款界面与设置

窄幅竖向窗口、CPU Models / NPU Models 双标签、搜索框、圆角模型卡片、置顶；设置含简体中文 / English / 繁體中文 三语即时切换、深浅主题、图片比例、步数(默认20)、CFG(默认7)、9 种采样器(默认 dpm)、负向提示词、图生图(默认重绘 0.45)、清理临时、检测更新。

③ 下载模型到当前目录

CPU 页 37 个标准 SD1.5 逐个下载，真实百分比/速度/断点续传，国内镜像（hf-mirror / 魔搭）优先、失败回退官方源，全部链接已实测可达；模型存程序当前目录 models。下载后点卡片即进入生成页。

④ 本地出图

桌面端直接读取 safetensors 无需转换；正/负提示词、比例 1:1/3:4/4:3、步数、CFG、采样器、随机/指定种子、图生图、生成数量；真实采样进度 + 预览 + 历史，成品存 output。

⑤ NPU 页如实加锁

NPU 页列出 Z-Image Turbo、FLUX.2 Klein、千问 Qwen Image 2.1×4、Illustrious v16/dmd2、CyberRealistic v10/dmd2 与 SD1.5 QNN 变体共 15 个；它们依赖手机骁龙 NPU/QNN/MNN，电脑 CPU 引擎不能运行，一律加锁并三语说明，不提供会失败的假下载/假生成。

模型下载到程序当前目录的 models 文件夹（安装目录或绿色包目录内），图片存于 output；仅当装在 Program Files 等受保护目录时才回退到 %LOCALAPPDATA%\LocalDreamET 并在界面明示。SD1.5 每个约 2.1–2.5GB，老旧 CPU 出图较慢属正常。说明：电脑版当前为 CPU 引擎，能否使用 NPU 取决于电脑实际硬件与后端；本安装包的真实出图/下载效果请在 Windows 真机验收，如遇问题请回传程序目录 tmp 内的 sd-cli 日志与“设置→关于”版本号。
