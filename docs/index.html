手机版当前 v3.0.0-et.77，约 153 MB，含 arm64-v8a / armeabi-v7a / x86_64 三套原生引擎，包名 etc.github.ai，签名 CN=ET。装完在「关于/版本」看到 build 151 即新版。更早版本的逐条修复见 GitHub Release 说明。按下面 6 步使用：

① 下载安装 App
点上方「手机 APK」下载固定名 LocalDream-ET.apk，允许安装未知来源。安装后在「关于/版本」核对 build 号；三架构引擎已内置。
② 授予「所有文件访问」权限
首次使用请在系统设置里给 App「所有文件 / 管理所有文件」权限，否则读不到公共目录里的模型，模型列表会是空的。
③ 下载 / 选择模型
把模型放到公共目录 LocalDreamET/models；带转换流程的模型会自动转换一次，anythingv5cpu 等 CPU 直读模型无需转换。文件齐全即就绪、缺文件置灰。
④ 本地出图 / 修图
输入提示词 → 选模型 → 出图；修图在「修图」里上传整图、设重绘强度（0.3–0.7，默认 0.45）。英文提示逐词透传。
低端机（32 位 / 无半精度 / 2–3GB，如 PowerVR GE8320）默认强制安全档：长边 256、8 步、euler_a、单张；约 164 秒/步是硬件地板，软件无法快一个数量级，不承诺秒出。
「设置 → 强制出图」默认关；打开后不再自动降档、按你选的分辨率/步数硬跑——低配机可能崩溃或极慢，需自行承担风险。
⑤ 可选：API 连接 / 用电脑服务端出图
手机「设置 → API 连接」选一个就绪模型，手机即变成局域网出图服务器（前台服务常驻、WakeLock 保活），其它设备可连 http://手机IP:8082。也可用上方「下载服务端」在 Windows/Linux 跑 v1.1.7：启动即先绑定端口、引擎后台加载，/healthz 就绪后对外提供 SD1.5 的 txt2img/img2img，默认无内容限制。聊天客户端「ET 聊天画师」v1.0.2 连接服务端出图。
⑥ 常见问题：内存不足 / 太慢怎么办
  • std::bad_alloc 内存不足：降分辨率/步数；低端机保持 256/8 安全档，或改用电脑服务端。
  • 8081 启动失败：模型未下完、未转换完成或 ABI 不匹配。
  • x86 模拟器跑不了 ARM 原生引擎，出图需真机；模拟器只能验证 UI。
  • 连续/多张出图引擎复用、每张立即落盘，第二张不重启不丢图。

本站已启用 HTTPS。但微信/QQ 可能对未在中国大陆 ICP 备案的第三方域名（含 github.io 及本自定义域）直接安全拦截（“已停止访问”），这是平台侧限制、网页无法解除；被拦截时请用系统浏览器打开，或到 GitHub Release 页下载。如需在微信内稳定访问需自备已 ICP 备案域名（本版不提供）。

聊天式出图客户端（新 APK，独立安装）

全新 etc.github.ai.chat「ET 聊天画师」v1.0.2：标准聊天界面（顶部标题+设置，中间消息气泡流，底部固定“图片 + / 输入框 / 发送”栏，默认深色），手机自身不带模型，连接电脑上已就绪的 Local Dream ET Server v1.1.7 或主 App 的“API 连接”服务出图，可与主 App 同时安装。

  • 右上角设置里填：服务端地址（http://电脑物理网卡IP:8080）、46 位 API Key、AI/模型名，并可设置全局反推理（负面）提示语，保存即全局生效；“连接测试”就绪/模型加载中/连不上三态中文提示（3 秒超时+自动重试），失败给出同 WiFi/物理网卡地址/防火墙放行 8080/服务端已就绪的排查清单。
  • 一键扫描局域网：自动枚举手机所在 192.168/10.x 网段并发探测 8080 的 /healthz，命中即可点选自动填入（200 标注就绪、503 标注模型加载中），免去手填 IP、避免误填 172.x 虚拟网卡。
  • 回对话页：输中文提示词即文生图；也可上传图片让 AI 修图（图生图，带重绘幅度滑杆）。AI 返回的图直接在左侧气泡内按网格内联显示，返回几张显几张（服务端批量 6 就显示 6 张），点开可全屏、保存相册、分享、云上传。
  • v1.0.2 修复“发送后没反应”：点发送立即显示右侧用户气泡与左侧“AI 生成中”气泡，失败在气泡内给中文并可一键重试；会话与图片本地持久化，返回页面或重开 App 记录仍在。

用法：先在电脑启动服务端并等模型下载完整、界面显示就绪；复制其服务地址 / API Key / 模型名到本 App 设置并保存即可。批量步数默认跟随服务端（设置里可单独指定）。本客户端不出图在本地，完全依赖局域网内的服务端。

功能

  • 完全离线的文生图与图生图：英文提示逐字透传，中文提示本地或可选联网增强，不强制上传。
  • SD1.5 支持 CPU 与 GPU（OpenCL），GPU 初始化失败自动回退 CPU。
  • 出图健康检测：识别碎玻璃/NaN 时自动关闭 OpenCL、用 CPU 安全参数重试一次，并记住本机 GPU 不稳定。
  • 应用内检测更新：GitHub 优先、Gitee 兜底（Gitee 镜像需配置后开通），支持断点续传。
  • 本地日志与导出诊断：右上角“日志”查看引擎/下载/转换/生成/更新/云上传。
  • 可选 GitHub/Gitee 私有云备份（PAT），图片与日志备份到你自己的私有仓库。

模型与机型兼容

模型架构支持范围
SD1.5（含 Anything 系列） arm64-v8a / armeabi-v7a / x86_64 全部 64 位安卓机（华为麒麟、联发科、Exynos、Tensor 等）CPU/GPU 可跑，无 OpenCL 回退 CPU；32 位设备支持 CPU/GPU；x86_64 模拟器可原生跑 CPU。
SDXL / DiT / 千问等大模型 QNN NPU（libdit_engine） 当前仅骁龙 Hexagon NPU（SM8650/8750 级别）。华为等无 Hexagon 的机型不支持，App 会如实锁定、不假标。

性能取决于设备，生成耗时随分辨率平方与步数增加，不承诺秒出或 4K。图片尺寸长边按内存自适应：≤6GB 512、≤10GB 640、>10GB 768（均 64 对齐），比例支持 1:1 / 2:3 / 3:4 / 4:3 / 3:2 / 9:16 / 16:9 与自定义。

修图模式

新增整图 img2img 工作台：选择已下载且本机可用的模型 → 上传整张图片（不裁剪、不分割）→ 输入中文正向/负向提示 → 调整重绘强度（0.3–0.7，默认 0.45）→ 结果写入历史，可保存到相册或云备份。

自动反推提示词（tagger）暂未内置，目前请用中文直接描述想把图改成什么样子。

更新机制与安装

  • 检测更新读取 update.json，GitHub 主通道优先，失败自动回退镜像通道。
  • 「发现新版本」弹窗标题与更新内容由 update.json 的 title / releaseNotes 下发，更新说明首行为联系作者说明，支持换行。
  • 下载走前台服务并显示进度通知；断点续传校验 206/Content-Range，不盲目删 .part。
  • 安装优先 PackageInstaller，失败回退系统安装器并引导“未知来源”。

云备份与令牌

  • 登录使用个人访问令牌（PAT），不内嵌网页收账号密码。GitHub classic 令牌勾选 repo；fine-grained 令牌需 Administration + Contents 权限。
  • 建仓遇 403（fine-grained 无建仓权限）时，可用“使用已有仓库”手动绑定你已建好的私有仓库。
  • Gitee 使用私人令牌（设置 → 私人令牌，勾选 user_info / projects）。
  • GitHub 设备码登录需开发者自行注册 OAuth App 并填入 client_id；未配置时入口暂不可用。
  • “关注开发者 / 点 Star”默认勾选、可取消，失败不影响登录与上传。
  • 令牌仅存 Android 系统密钥库，不写入日志或导出文件。

帮助与日志

常见问题与错误说明见 帮助页。日志位置：App 内右上角“日志”、导出诊断；公共目录 LocalDreamET/logs/app.log，以及 engine_*.log、convert_*.log。

  • 内存不足（std::bad_alloc）：降低图片尺寸或步数后重试。
  • 8081 启动失败：模型未下载完成、转换未完成或 ABI 不匹配。
  • x86 模拟器提示：使用已内置 x86_64 引擎的版本，或换 arm64 真机。
