FAQ

常见问题

出图很慢 / 提示内存不足？

降低分辨率与步数；低端机保持 256×256 / 8 步安全档，或改用 Windows / Linux 服务端出图。

NPU 不生效 / 模型不加载？

QNN NPU 仅骁龙 Hexagon 机型支持；其它机型自动用 CPU / GPU。模型需下载完整并完成转换后才会就绪。

为什么读不到模型列表？

请在系统设置给 App「所有文件访问」权限，并把模型放到公共目录 LocalDreamET/models。

微信里打不开 / 提示已停止访问？

第三方域名可能被微信拦截，请点右上角「···」用系统浏览器打开。
