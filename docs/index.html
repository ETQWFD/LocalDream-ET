检测更新如何工作

更新清单由本官网（GitHub Pages）提供，应用启动检测时读取 update.json，版本号更高则提示更新。

  1. 打开 App → 右上角菜单 → 设置。
  2. 点击最下方的 检测更新，应用联网比对 versionCode。
  3. 有新版本时点「下载并安装」，安装包在应用内下载并实时显示百分比与已下载大小。
  4. 首次使用会跳到系统设置，允许本应用「安装未知应用」，返回后自动继续。
  5. 下载完成立即调起安卓系统打包安装程序（Package Installer），确认即可覆盖安装，全程不经过文件管理器或应用商店。

安装说明

① 下载 APK

点击顶部「下载最新 APK」，或到 GitHub Releases 下载 LocalDream-ET.apk。

② 允许安装

安装时若系统提示，请允许当前浏览器/应用「安装未知应用」。

③ 下载模型

首次进入在模型列表选择 SD1.5 / SDXL 模型下载；CPU/GPU 模型适配更多机型。

④ 开始生成

输入提示词即可本地出图，无需联网上传图片。

架构与机型兼容

安装包包含两种 ABI，系统会自动匹配。

arm64-v8a · 64 位 NPU 加速（骁龙） CPU / GPU armeabi-v7a · 32 位 仅 CPU / GPU

✅ 32 位：v3.0.0-et.2 起安装包已内置 armeabi-v7a 原生 CPU/GPU（MNN/OpenCL）引擎，32 位手机可直接转换模型与出图，无需自行编译。NPU 所用的高通 QNN 库仅有 64 位版本，因此 32 位设备走 CPU/GPU 引擎； 大模型（尤其 SDXL）对内存要求较高，32 位设备建议使用 SD1.5。

电脑版（Windows x64）

使用 C 语言编写的原生桌面启动器，底层为开源 stable-diffusion.cpp（leejet, MIT）CPU 引擎，Windows 10/11 64 位本地离线出图，免费、不上传图片。右键程序“属性→详细信息”显示开发者 ET。

① 下载安装

点顶部「下载电脑版安装包 v2.2.0」（按用户安装、无需管理员），或下免安装 ZIP 解压即用；安装版自动创建桌面与开始菜单快捷方式。v2.2.0 模型增至 13 个，延续大模型断点续传/防损坏下载。

② 下载模型

左侧手机式卡片列表+搜索框，7 个模型逐个下载、真实百分比、断点续传，默认国内镜像、失败回退官方源：Absolute Reality、Realistic Vision V5.1、majicMIX v7、Analog Madness v7、DreamShaper 8、Counterfeit V2.5、Qwen-Image 2.1 UC。

③ 本地出图

桌面端直接读取 safetensors 无需转换；图生图整张上传不裁剪；比例 1:1/3:4/2:3/9:16/4:3/3:2/16:9（SD 按 64、Qwen 按 32 对齐）；真实采样进度条+实时预览；深浅主题、中文/English；应用内检测更新自动安装。

模型下载到程序同级 models 文件夹（安装目录或绿色包目录内），图片存于同级 output；仅当装在 Program Files 等受保护目录时才回退到 %LOCALAPPDATA%\LocalDreamET。SD 模型每个约 2.1GB，Qwen 整套约 10.6GB（建议 16GB 内存或独显），下载后离线可用。
